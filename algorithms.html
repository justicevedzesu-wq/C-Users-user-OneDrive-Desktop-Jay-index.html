Algorithms & Problem Solving

Learn how to analyse problems and develop step-by-step solutions that can be implemented by computers.

What is an Algorithm?

An algorithm is a finite sequence of clear and well-defined steps used to solve a problem or perform a task.

Characteristics of a Good Algorithm

  • It must be clear.
  • It must have a definite beginning and end.
  • Each step must be unambiguous.
  • It should eventually terminate.
  • It should produce the expected result.

Example Algorithm

Problem: Find the larger of two numbers.

1. Start

2. Enter two numbers A and B

3. Compare A and B

4. If A is greater than B, display A

5. Otherwise, display B

6. Stop

Pseudocode

Pseudocode is a simple way of writing an algorithm using ordinary language and programming-like structures. 

START

INPUT A
INPUT B

IF A > B THEN
    DISPLAY A
ELSE
    DISPLAY B
END IF

STOP

Flowcharts

A flowchart is a graphical representation of an algorithm. It uses symbols to show the flow of operations.

  • Oval – Start/End
  • Rectangle – Process
  • Parallelogram – Input/Output
  • Diamond – Decision
  • Arrow – Flow direction
