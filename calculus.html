Calculus

Learn limits, differentiation, integration and the applications of calculus.

What is Calculus?

Calculus is a branch of mathematics used to study change, motion, rates and accumulation.

Calculus has two major areas:
  • Differential Calculus
  • Integral Calculus

Limits

A limit describes the value that a function approaches as the input approaches a particular value.

Example

lim (x → 2) (x + 3)

= 2 + 3

= 5

Differentiation

Differentiation is used to determine the rate at which a function changes.

Basic Rule

If:

y = xⁿ

Then:

dy/dx = nxⁿ⁻¹

Example

y = x³

dy/dx = 3x²

Integration

Integration is the reverse process of differentiation and can also be used to find areas under curves.

Basic Rule

∫ xⁿ dx = xⁿ⁺¹/(n + 1) + C

Example

∫ x² dx

= x³/3 + C

Applications of Calculus

  • Finding rates of change
  • Finding maximum and minimum values
  • Finding areas under curves
  • Studying motion
  • Optimization
  • Engineering applications
  • Economic modelling
